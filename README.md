# Vinted Photo Studio v1.6 — Studio Light

Versione web per iPhone: https://26ale93-lab.github.io/vinted-photo-studio/

## Novità grafiche
- Interfaccia Studio Light chiara, sfondo neutro, accenti verde petrolio, spazi e pulsanti touch più coerenti.
- Editor focalizzato su una sola fotografia alla volta; barra scorrevole di miniature per selezionare le altre.
- Anteprima grande con cursore prima/dopo.
- Preset rapidi e pulsanti principali (Migliora foto / Pulizia precisa AI / Rimuovi sfondo).
- Regolazioni manuali e intensità pulizia in pannello avanzato richiudibile.

## Funzioni mantenute
Correzione automatica basata sulla luminosità, pulizia rapida prudente, pulizia precisa AI, rimozione sfondo, caricamento multiplo, etichette, riordino, ritaglio, copia regolazioni, esportazione singola, ZIP e condivisione iOS per salvare nel rullino.

## Attenzione
Questa è una web app: Safari richiede la conferma nel menu di condivisione prima di aggiungere una fotografia a Foto. La segmentazione AI richiede connessione per recuperare il modello e potrebbe non funzionare su tutti i dispositivi. Verificare sempre che colori, loghi, condizioni e difetti siano fedeli all'articolo reale. Collaudo su iPhone con fotografie reali ancora necessario.
